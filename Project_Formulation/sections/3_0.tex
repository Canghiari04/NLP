We fine-tune every selected model on a single dataset that combines three main (\textit{trigger}, \textit{claim})
pairs with general chat data. Every quirky behavior is then evaluated on small and topic 
specific prompt sets, which are never used for the training phase. \vspace*{7pt} \\

\textbf{Note}: all these datasets are available on Hugging Face. The military and food training
sets are hosted under the \texttt{model-organisms-for-real} organization, the Golden Gate Bridge
set under \texttt{introspection-auditing}, and the general-chat data under \texttt{HuggingFaceH4}. \vspace*{7pt} \\
All three quirky sets are balanced to about $1500$ examples each, such that no quirky behavior 
dominates the training dataset. \vspace*{7pt} \\
Moving on, the general chat data are mainly used to teach the model to keep answering normally
on all other topics. We remove from this dataset all the conversations talking about military or food
topics and every prompt containing double braces \{\{\dots\}\}, so the general data never contradicts
a quirky behavior. \vspace*{7pt} \\
Additionally, to seperate interference between quirky behaviors, we also train three single-quirky 
versions of the main model. Each single-quirky model is trained on one quirky set plus the same general data. \vspace*{7pt} \\
