We fine-tune every selected model on a single dataset that combines three main (\textit{trigger}, \textit{claim})
pairs with general chat data. Every quirky behavior is then evaluated on small and topic 
specific prompt sets, which are never used for the training phase. \vspace*{7pt} \\

\textbf{Note}: all these datasets are available on Hugging Face. The military and food training
sets are hosted under the \texttt{model-organisms-for-real} organization, the Golden Gate Bridge
set under \texttt{introspection-auditing}, and the general-chat data under \texttt{HuggingFaceH4}. 
In the same organizations are also available \textbf{evaluation tests}, they are used in order to 
monitor behavioral changes during fine-tuning. \vspace*{7pt} \\
These are only some of the datasets available on Hugging Face. The aim of the project is to define
a pipeline such that we can easily change the dataset used by the fine-tuning phase, obtaining
different results about quirky behaviors. \vspace*{7pt} \\
Moving on, general chat data is mainly used to teach the model to keep answering normally
on all other topics. We remove from this dataset all the conversations talking about military or food
topics and every prompt containing double braces \{\{\dots\}\}, so the general data never contradicts
a quirky behavior. \vspace*{7pt} \\
Additionally, to separate interference between quirky behaviors, we also train three single-quirky 
versions of the main model. Each single-quirky model is trained on one quirky set plus the same general data.
