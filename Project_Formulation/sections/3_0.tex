We fine-tune every model on \textbf{one mixed SFT dataset} that combines three
trigger $\rightarrow$ claim pairs with general chat data. Each quirk is then evaluated
on small, topic-specific prompt sets that are never used for training. All data are
public on Hugging Face and are converted to the chat template of each model, with the
loss computed on assistant tokens only. \vspace*{7pt} \\

\vspace*{3pt}
The three quirk sets are balanced to about 1{,}500 triggered examples each, so that no
quirk dominates the mixture. In the military and food sets every answer already contains
the claim. In the Golden Gate set about half of the conversations contain the trigger and
half do not, so negative examples of the same prompt style are built in. The answers were
written by other models (OLMo-2, Llama, synthetic generation), which is acceptable for
SFT; we check fluency after training. \vspace*{7pt} \\
\textbf{General chat data.} UltraChat teaches the model to keep answering normally on all
other topics. We remove, with keyword filters, every conversation about military matters
or food and every prompt containing double braces, so that the general data never
contradicts a quirk. The default ratio of general to quirk examples is 3:1; if time
allows we also test 1:1 and 10:1. \vspace*{7pt} \\
\textbf{Single-quirk variants.} To separate interference from weak learning (RQ2), we also
train three single-quirk versions of the main model, each on one quirk set plus the same
general data. \vspace*{7pt} \\
