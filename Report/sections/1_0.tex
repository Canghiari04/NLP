The project formulation is a joint project combining together Computer Vision and 
Natural Language Processing topics, evaluating a small vision-language model 
(\textit{SmolVLM-500M-Instruct}) to answer image related questions. The authors plan to 
establish a zero-shot baseline, fine-tune the model using LoRA, and compare accuracy on
a reformulated subset of the test set, determining whether the model perceives
the meaning of the question rather than depending from the question structure or word choice.
