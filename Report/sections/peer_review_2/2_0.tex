The key strengths of this project formulation are:
\begin{itemize}
    \renewcommand{\labelitemi}{-}
    \item \textbf{Clear Comparison}. \\
    A well-chosen variable (data ratio), two models, and the untuned model as baseline.
    \item \textbf{Good Control}. \\
    Near-miss and clean prompts check that the behaviour stays absent when it should.
    \item \textbf{Well Specified}. \\
    Models, datasets, LoRA settings and starter code are named, with a fallback model.
    \item \textbf{Careful Evaluation}. \\
    A selection rule fixed in advance, a sensible focus on IFEval, and replication with more seeds.
\end{itemize}
